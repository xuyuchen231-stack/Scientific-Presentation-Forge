# Evidence, equations and references

Build an evidence ledger before writing claims. Store source IDs in `sources`: `id`, `citation` (short author/year), `reference` (complete bibliographic entry), `locator` (page/figure/table or data file), and `verified` (boolean). Add DOI/URL where applicable. Use notes to document extraction, transformations, exclusions and limitations relevant to the claim. Verifying a DOI alone does not verify a numerical claim: compare with the relevant page/table and experimental conditions.

For paper reports, extract question, claimed contribution, mechanism, datasets, controls, evaluation protocol, principal findings and conclusions. Retain attribution and scope when compressing. Use an original PDF figure when underlying data is absent, and crop by verified bounding box. Do not redraw quantitative points by eye or use a generative image model. For scanned documents, use available OCR and compare all quantitative content with the page image.

For user data, preserve the input file, checksum, column meanings, units, preprocessing and plotting code. Describe repeated measurements and the actual uncertainty statistic. Keep missing values explicit; do not interpolate unless analytically justified and recorded. Record raw, normalized, simulated, digitized or predicted status per series. Validate split boundaries and batch identity for machine learning. Distinguish interpolation, one-step prediction and free-running dynamic prediction.

For formulas, compare each symbol, numerator/denominator, sign, integration bound and index against the original. Add a short symbol/unit key. Explain assumptions verbally or in notes. For a mass-balance model include relevant volume/feed dilution terms when specified by the source; never add a decorative equation unrelated to the implemented model. Use native PowerPoint text for simple Unicode expressions and supplied reviewed OMML for fractions/matrices. Keep LaTeX alongside OMML. Do not claim image/SVG equations can be edited as equations.

Use original articles and official metadata when adding external evidence. Verify current publication details through available research tools. Make visible citations concise and put full entries in the appendix. Record adapted/redrawn figures as such; keep asset permissions and source notices with the rebuild assets. Claim certainty should reflect the cited results without filling the presentation with generic defensive language.
